# HalfLifeWeek2-CAD
Guide: https://github.com/karnxx/merbl/blob/main/guide.md

I made the marble track. I decided to make 2 different tracks that end in the same place. I also wanted to create all the special tracks that were in the guide, so my track has a funnel, plinko board, and stairs. This is how the final result looks like:

![Final result](./Pictures/Final%20Result.png)

The first track goes around into a funnel, and ends in the plinko board. The second track goes around the other way, into the stairs, and comes around again into the plinko board. At the end of the plinko board is a box to catch the marble.
